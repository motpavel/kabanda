# Упрощение выхода в рейд

База: ba2b7e4ef4ebb922d0379d50a045a4126d815d4b. Изменяем рабочее приложение, не прототип.

- [x] Развести новый маршрут и выход в рейд; каталог перед историей; широкое основное действие.
- [x] Две иллюстрированные карточки режима → короткая форма; автоматическое название.
- [x] Свободная охота по выбранному типу точек, серверные снимки КБ и достопримечательностей.
- [x] Сейчас/запланировать, дата и время, необязательные место старта и заметка; восстановление отправки без дубликатов.
- [x] Переходы без перезагрузки документа, reduced motion; мобильные поля без горизонтального переполнения и автозума.
- [ ] Проверить оба режима, регрессии, мобильные ширины и выложить общий релиз.

Границы: создание маршрута не запускает поездку; создание выезда не обходит проверку готовности/сбор стаи. Участники всей Кабанды могут присоединиться через существующий сбор; персональное приглашение дополнительно доступно ссылкой рейда. Не сохраняем устаревшие права или GPS-запись в декоративном кэше экранов. Не отключаем пользовательский pinch-to-zoom.

Проверено локально: typecheck, unit suite (PWA 188), PostgreSQL 59, golden/offline E2E 2. Ручная проверка участником: оба режима, запланированная поездка с местом старта и заметкой; ширины 320/390/1280 без горизонтального переполнения. Публикация требует migration 0016 и проверки exact build на домене.
