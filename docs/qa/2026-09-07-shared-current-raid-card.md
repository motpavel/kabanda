- Two-column metrics: numeric values 20px, labels 13px, textual state 16px. Icons 24px. CTA at least 48px.

- Navigator metric indicates assignment, not an invented live GPS readiness state.
- No database migration, no changes to raid commands, GPS, access control, creation forms or production ride data.
