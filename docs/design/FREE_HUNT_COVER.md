# Обложка свободной охоты

Использовано изображение, предоставленное пользователем 5 сентября 2026. Без генерации и изменения содержания; сохранена JPEG-копия для приложения: `apps/pwa/public/brand/kabanda-free-hunt-v1.jpg` (1312×1199).

Обложка показывается в форме создания свободного рейда, карточке текущего рейда без `routeTemplateId` и быстром сценарии выбора участников в `/prototype/raids`. Для пользовательского маршрута сохраняется прежнее оформление. Исторические карточки не заменялись, поскольку их DTO пока не сообщает режим рейда.
